# Reproducibility

The paper figures and tables can be regenerated from the source scripts. The
public repository does not need committed `results/` artifacts. The default
figure format is PDF.

## Environment

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e .
```

Optional tools:

- LaTeX for paper-style text rendering in figures.
- Ghostscript for converting PDF text to outlines.

## One-command Reproduction

```bash
PYTHONPATH=src .venv/bin/python scripts/reproduce_paper_artifacts.py --clean
```

This command recreates the supported `results/` tree, paper figure/table
outputs, ACTIVSg2000 replica artifacts, quantitative tables, replication
subsection figures, and finite-window proxy data.

Use `--dry-run` to print the exact command sequence without running the
simulations.

## Core Case-Study Dataset

```bash
PYTHONPATH=src .venv/bin/python scripts/run_paper_case_sweep.py \
  --out results/paper_case_studies/dataset
```

This writes normalized systems, assets, events, K matrices, validation rows,
observability cases, uncertainty frontiers, mitigation summaries, and scaling
summaries under `results/paper_case_studies/dataset/`.

## Main Paper Figures And Tables

```bash
PYTHONPATH=src .venv/bin/python run_case_studies.py --skip-derive --strict
```

This writes the main case-study figures to `LaTeX/figures/generated/` and the
generated tables to `LaTeX/tables/generated/`. The `--skip-derive` flag tells
the renderer to use the normalized dataset generated by
`scripts/run_paper_case_sweep.py` rather than requiring committed per-case
result directories.

## Quantitative Tables And Mitigation Output

```bash
PYTHONPATH=src .venv/bin/python scripts/make_quantitative_case_elements.py
```

This writes validation, ablation, and mitigation summary tables plus the
mitigation LP output figure.

## Finite-Window Proxy Figure

```bash
PYTHONPATH=src .venv/bin/python scripts/generate_finite_window_proxy_figure.py
```

This searches benchmark channels for a clear non-monotone response and writes
the finite-window/proxy comparison figure and trace data.

## ACTIVSg2000 Academic Replica

```bash
PYTHONPATH=src .venv/bin/python -m pa_dvsa.replication.academic_replica --plot
```

This writes the supported large-benchmark mechanism replica artifacts to
`results/activsg2000_iberian_replication/` and the replication figure to
`LaTeX/figures/generated/`.

## Artifact Policy

Do not commit generated `results/`, local caches, virtual environments, TeX
installations, preview PNGs, or duplicate SVG/PNG debug outputs. Commit source
scripts, tests, docs, and the small modified ACTIVSg2000 input case under
`data/activsg2000_stable/`.
